# 회랑 2030 (CORRIDOR 2030)

브라우저에서 도는 1인칭 슈팅 게임. 2030년 제2차 한국전쟁, 비 내리는 새벽의 의정부 상가 골목에서 적 전파교란기 3기를 끊고 회수 지점까지 빠져나오는 단일 임무다.
모델·텍스처·소리 파일 없이 전부 실행 중에 코드로 만든다(three.js 0.180). 빌드하면 HTML 파일 하나가 된다.

## 실행

```bash
npm install
npm run dev      # http://127.0.0.1:5183
npm run build    # dist/index.html 한 파일로 묶음
```

마우스가 화면에 고정되지 않는 환경에서는 버튼을 누른 채 끌어서 둘러본다.

## 구조

| 경로 | 역할 |
| --- | --- |
| `src/main.js` | 진입점. 모듈을 차례로 올리고 프레임 순서를 정한다 |
| `src/core` | 이벤트 버스, 시드 난수, 상수, 품질 단계, 설정 저장 |
| `src/render` | 렌더러, 카메라 두 대(월드/총기), 조명, 하늘, 젖은 노면 반사, 후처리 |
| `src/mats` | 절차적 텍스처, 재질 라이브러리, 한글 간판 아틀라스 |
| `src/world` | 충돌·길찾기, 레벨 조립 도구, 소품, 레벨 |
| `src/fx` | 비, 입자, 예광탄, 탄흔, 탄피, 폭발 |
| `src/audio` | Web Audio 합성음과 잔향 |
| `src/game` | 입력, 플레이어, 무기, 적 AI, 임무 진행 |
| `src/ui` | HUD, 상황판(메뉴), 스타일 |

모든 모듈은 공용 객체 `G` 하나를 받아 만들어지고, 서로는 이벤트(`weapon/shot`, `enemy/down` 등)로만 알린다.

## 점검용 옵션

주소 뒤에 붙인다. 예: `/?go&mute&q=low`

| 옵션 | 뜻 |
| --- | --- |
| `q=low\|medium\|high\|ultra` | 그래픽 품질 고정 |
| `go` | 표지를 건너뛰고 바로 투입 |
| `mute` | 음향 끔 |
| `god` | 피해 없음 |
| `seed=숫자` | 레벨 난수 시드 |
| `cam=x,y,z,lx,ly,lz` | 고정 시점 |
| `shot` | 캡처용(저해상도 텍스처, 마우스 고정 안 함) |

콘솔에서는 `window.__corridor`로 상태를 본다: `stats()`, `step(프레임 수, dt)`, `cam(...)`, `errors`, `G`.
임무 흐름을 건너뛸 때는 `__corridor.G.game.cheat`의 `warp`, `cutNext`, `clearEnemies`, `reinforce`를 쓴다.

## 현재 상태 (v0.1)

첫 플레이 가능 버전이다. 무기와 적은 상자·원통을 조립한 임시 모델이고 사람 형태의 적은 없다. 임무는 하나뿐이다.
